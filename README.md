# Deep Learning Practices

This repository contains my deep learning practice projects developed while learning PyTorch fundamentals and neural network concepts.

## About

The goal of this repository is to build a strong foundation in deep learning through hands-on experimentation with PyTorch. The projects focus on understanding tensors, automatic differentiation, neural network training workflows, and convolutional neural networks.

## Topics Covered

### PyTorch Fundamentals

* Tensor Operations
* Tensor Manipulation
* GPU (CUDA) Support
* Device Management

### Automatic Differentiation

* Autograd
* Gradient Computation
* Backpropagation Fundamentals

### Neural Networks

* Building Neural Networks with PyTorch
* Forward Propagation
* Loss Functions
* Optimization with SGD

### Computer Vision

* MNIST Digit Classification
* Data Loading with DataLoader
* Convolutional Neural Networks (CNNs)
* Model Training and Evaluation

## Technologies

* Python
* PyTorch
* NumPy
* Matplotlib
* Google Colab

## Learning Objectives

Through these projects, I aimed to:

* Understand the fundamentals of deep learning
* Learn PyTorch's tensor and autograd systems
* Build and train neural networks from scratch
* Implement CNN architectures for image classification tasks
* Gain practical experience with GPU-accelerated training
